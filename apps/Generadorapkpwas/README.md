# Generador Apk Pwas

APK generado automáticamente desde una PWA o HTML con **Android Forge**.

## Info

- **Package**: `com.ejemplo.generadorapkpwas`
- **Modo**: PWA local (empaquetada)
- **Empaqueta archivos locales desde `app/src/main/assets/`**

## Cómo compilar manualmente

```bash
gradle assembleDebug
```

APK en: `app/build/outputs/apk/debug/app-debug.apk`
